# System Design Interview Handbook

A structured place to prepare for system design interviews. This first version is an outline: the question pages and concept pages are ready for explanations, diagrams, and examples to be added later.

1. [Common system design questions](common-questions/README.md) — practice widely used design prompts.
2. [Company interview questions](company-questions/README.md) — collect questions reported in public interview accounts, with sources.
3. [Key concepts](concepts/README.md) — build the vocabulary and trade-off reasoning needed for design interviews.
