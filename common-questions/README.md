# Common system design questions

This section is a practice question bank. Each page has the same outline so answers can be compared and expanded over time.

For each question, add the problem statement, requirements, scale assumptions, architecture, data model, APIs, bottlenecks, trade-offs, and possible follow-up questions. Diagrams can be added beside the Markdown pages when ready.

The prompts here are representative practice topics; they are not attributed to a specific company's interview.
